# Safety card

Before you run anything an AI (or a website) tells you to run:

1. **Do I know what it does?** If not, ask it to explain first, without running it.
2. **Does it change or delete anything?** Words like delete, remove, format, overwrite and sudo mean yes. Stop and ask.
3. **Can I undo it?** If not, make a copy first.
4. **Does it ask for a password or an administrator?** Not in this school's beginner lessons. If a lesson seems to need one, stop and ask a person.
5. **Did I check the answer somewhere other than the AI?**

When unsure: stop. Nothing in Build School is urgent.
