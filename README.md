# Make a plain PDF prettier with an AI agent

Two things in here. That's it.

## 1. A template for making a plain document prettier

**File:** [`TEMPLATE.md`](TEMPLATE.md)

Give an AI agent (Claude, ChatGPT, Gemini, Codex, any of them) two things:

1. Your plain PDF or Word document
2. `TEMPLATE.md`

Say: *"Use this template on this document and put the result in my Google Drive."*

The template tells the agent how to keep every word exactly as written, make it look good, and tell you honestly what it did and did not do.

## 2. Tips and tricks for getting started with AI

**File:** [`TIPS_AND_TRICKS.md`](TIPS_AND_TRICKS.md)

Plain-language advice for using large language models and AI agents. No coding.
